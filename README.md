# Trace Evidence Lab

Small, reproducible experiments for understanding where inference systems actually spend their
time. Each experiment keeps the workload, metric definition, comparison, and uncertainty visible.

This repository is independent work by Ankit Gala. It is not a vendor benchmark suite and it does
not claim that one GPU, engine, or configuration is universally best.

## Experiments

| Experiment | Question | Status |
|---|---|---|
| [`gpu-upgrade`](experiments/gpu-upgrade/) | Did a newer GPU improve the response, or did the workload bottleneck live elsewhere? | Recorded result + checked receipt |
| [`two-clocks`](experiments/two-clocks/) | When load rises, did generation slow down or did requests wait longer to start? | Recorded result + checked receipt |

## Evidence classes

- **Measured by us** — values recorded from a named run, workload, and environment.
- **Derived** — arithmetic or diagnosis computed from measured inputs.
- **Configured** — a setting selected before a run, not an observed result.
- **Released/documented** — a fact from a public versioned artifact.

The lab never treats a configured threshold as a measurement, and never turns one workload into a
universal recommendation.

## Working style

Each experiment includes a short README, machine-readable observations, a checker, and the receipt
generated by that checker. The checker verifies arithmetic and boundaries; it does not pretend to
re-run a GPU campaign on a laptop.
